# Working rules for this repo

This curriculum is built one phase per session (see [PLAN.md](PLAN.md) for the
full phase table and module scope, [PROGRESS.md](PROGRESS.md) for current
status).

## End of each phase

Update `PROGRESS.md`: "Completed", "Next", and — only if something a *later*
phase actually needs to know exists (a convention, a chosen tool, an
environment quirk worked around) — a note under "Carried-forward notes". Skip
that section if there's nothing to carry forward; don't pad it.

Then commit, push, and stop (don't start the next phase in the same session).

## Delegating to subagents

Give a subagent only the slice it needs for its specific piece of work: the
relevant module scope from PLAN.md, the relevant carried-forward notes from
PROGRESS.md, and the folder/file conventions — not the entire plan, not the
full progress history.
