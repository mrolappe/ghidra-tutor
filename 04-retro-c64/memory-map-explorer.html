The 6510's full $0000–$FFFF view, left, plus a mode selector that recolors the three bank-switched ranges ($A000–$BFFF, $D000–$DFFF, $E000–$FFFF) exactly as 02-memory-map-bank-switching.md's condensed, no-cartridge (GAME=EXROM=1) mode table documents. $8000– $9FFF stays RAM in every row of that table — a cartridge (not modeled by this selector) is the only thing that can put ROM there.
